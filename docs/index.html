盤面タスク

純正リマインダーの上位2件を、Apple Watch の文字盤に常時表示するアプリです。 腕を上げるだけで「いま何をやるか」が見えます。

使いはじめる

  1. iPhone で盤面タスクを開き、リマインダーへのアクセスを許可します。
  2. Apple Watch で文字盤を長押し → 「編集」 → 横長のスロットに「盤面タスク」を置きます。
    対応する文字盤: モジュラー / モジュラーコンパクト / インフォグラフ モジュラー
  3. iPhone の一覧をドラッグして並べ替えると、上の2件が文字盤に出ます。

自動で最新にする（任意・1回だけ）

純正リマインダーを閉じた瞬間に文字盤を更新するには、ショートカットのオートメーションを1つ作ります。

  1. 「ショートカット」アプリ → 「オートメーション」タブ → 右上の「＋」
  2. 「App」 → 「リマインダー」にチェック → 「閉じられている」
  3. 「すぐに実行」を選ぶ → 次へ
  4. アクションで「盤面タスクを更新」を検索して追加 → 完了

設定しなくても、文字盤をタップすればその場で最新になります。

よくある質問

文字盤の表示が変わらない

文字盤をタップして Watch アプリを開くと、iPhone に問い合わせて更新します。 それでも古いままなら、スロットから一度外して置き直してください。

純正リマインダーで並べ替えたのに、順番が違う

純正アプリの手動の並び順は、アプリから読み取れません（Apple が公開していないため）。 盤面タスクは「優先度」を順番として使います。盤面タスクの中でドラッグすると、 その順番が優先度として保存され、純正アプリでは「!」の数として見えます。

予定（カレンダー）も出したい

iPhone の画面で行数と、そのうち何行を予定に使うかを選べます。 これから24時間以内で、まだ始まっていない予定が出ます。

Apple Watch を持っていない

iPhone のホーム画面ウィジェットだけでも使えます。同じ一覧が出て、○を押して完了できます。

データの扱い

データは iPhone のリマインダーとカレンダーにあるものだけです。 アプリが独自に保存するものはなく、開発者のサーバーもありません。 詳しくは プライバシーポリシー をご覧ください。
