# 案2 検証：priority で手動並び順を代替できるか

Apple Watch の文字盤に「基本」リストの上位2件を出す構想のうち、
**並び順をどう決めるか**を確定させるための検証。

## 背景

純正リマインダーでドラッグして作った並び順は、EventKit API から取得できない。
そこで `EKReminder.priority`（0〜9 の整数）を順位の保存場所として流用できないかを確かめる。
純正 UI は「低・中・高」の3段階しか見せないが、内部は9段階ある——という前提が成り立つかが焦点。

## 検証項目

| # | 内容 | 落ちた場合の影響 |
|---|---|---|
| R1 | 2,3,4,6,7,8 といった中間値を保存・再読込できるか | 3段階しか使えず、順位表現が事実上破綻 |
| R2 | 純正アプリで項目を編集した時に 1/5/9 へ丸められないか | 触るたびに順序が壊れる。案2は不成立 |
| R3 | iCloud 同期後も中間値が保たれるか | Mac で付けた順序が iPhone で消える |
| R4 | EventKit の生の fetch 順が手動並び順と一致しないか | （ボーナス）一致すれば案2すら不要 |

## 実行手順

Mac mini のターミナルで。Xcode プロジェクトは不要、`swift` コマンドで直接動く。

初回実行時に「ターミナルがリマインダーへのアクセスを求めています」が出るので許可する。
出ない場合は システム設定 > プライバシーとセキュリティ > リマインダー でターミナルを追加。

### 0. リスト名の確認

```sh
swift ReminderProbe.swift lists
```

### 1. R4：生の並び順を見る

**先に iPhone の純正リマインダーで「基本」を手動で並べ替えておく**こと。
並べ替えていない状態だと作成日順と区別がつかず、検証にならない。

```sh
swift ReminderProbe.swift dump 基本
```

`[A] fetch順` と `[B] 作成日順` が出る。iPhone の画面と見比べる。

- `[A]` が一致 → 手動並び順がそのまま取れている。**大当たり、案2不要**
- どちらも不一致 → 想定通り。次へ

### 2. R1：中間値を書き込んで読み直す

```sh
swift ReminderProbe.swift spread 基本
```

作成日順に priority 1,2,3... を書き込み、**別の EKEventStore で読み直して**検証する。
同一ストアだとメモリ上のキャッシュを見て通ってしまうため、必ず読み直す作りにしてある。

全て `OK` なら R1 合格。

### 3. R2：純正アプリに触らせる

ここが本番。

1. iPhone の純正リマインダーで「基本」を開く
2. 適当な1件の**タイトルを編集**して保存
3. さらに**新規リマインダーを1件追加**
4. 数分待つ（同期のため）
5. Mac で再度 `swift ReminderProbe.swift dump 基本`

- 編集した項目の priority が中間値のまま → **R2 合格。案2で確定**
- 1/5/9 に丸められた → R2 不合格。案2は3段階運用に縮小するか、設計を見直す

同じ確認を数分あけて行えば R3（同期）も同時に取れる。

### 4. 後片付け

```sh
swift ReminderProbe.swift clear 基本
```

検証で書き込んだ priority を全て 0 に戻す。純正アプリ側の「!」表示も消える。

### おまけ：非公開プロパティの調査

```sh
swift ReminderProbe.swift probe 基本
```

`EKReminder` とその親クラスのプロパティ一覧を Objective-C ランタイムから吸い出し、
`order` / `sort` / `index` / `position` などを名前に含むものを抜き出す。

何か出てきた場合は、並べ替えの前後で `dump` を実行して値が連動するか確認する。
連動していれば iPhone アプリ単体で真の並び順が取れることになる。
非公開 API なので App Store には出せないが、自分用のサイドロードなら問題ない。

## 判定後の分岐

- **R1・R2・R3 すべて合格** → 案2で実装に進む。自作アプリ側にドラッグ並べ替え UI を付け、順位を priority 1〜9 に焼く
- **R2 が不合格** → priority は「高」だけを浮上フラグとして使い、残りは作成日順にする折衷案へ
- **R4 が合格** → 上記すべて不要。fetch 順をそのまま使う
